## Dark/white annotation strategy

The InterPro_description column in seminavis_pnps_per_gene.tsv provides the functional domain annotation for all 36,254 genes. This annotation was generated by the paper authors using InterProScan v5.31 on the ORCAE platform, which integrates multiple domain databases including Pfam, SMART, CDD, etc.

- **Dark genes**: InterPro_description == "-" (no domain hit from any InterPro member database)
- **White genes**: InterPro_description != "-" (at least one domain hit)

This is equivalent to or stricter than a Pfam-only E<1e-9 threshold because:
1. InterPro integrates Pfam; if a gene has no InterPro hit, it has no Pfam hit
2. Pfam uses gathering thresholds (typically stricter than E<1e-9)
3. InterPro also includes SMART, CDD, etc., so some genes called "white" by InterPro would be "dark" by Pfam-only — making this a conservative estimate of the dark/white difference
